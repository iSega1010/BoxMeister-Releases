# Установка BoxMeister

Текущий пакет предназначен для КОМПАС-3D v22 x64 на 64-разрядной Windows. Требуется .NET Framework 4.5 или новее и доступ к GitHub.

1. В разделе Releases скачайте BoxMeisterSetup.exe.
2. Запустите файл и подтвердите запрос Windows на права администратора.
3. При необходимости укажите KOMPAS.exe установленного КОМПАС-3D v22.
4. Прочитайте условия и нажмите «Проверить и скачать».
5. После загрузки ознакомьтесь с лицензией выбранного выпуска и подтвердите согласие.
6. Сохраните документы и закройте КОМПАС. Нажмите «Установить».
7. Запустите КОМПАС. В меню «Приложения» откройте BoxMeister и команду «Создание развертки».

Файлы устанавливаются в Program Files/BoxMeister. Библиотека подключается автоматически при запуске КОМПАС.

## Обновление

В окне BoxMeister откройте «Проверка обновления». Нажмите «Проверить обновления». При наличии совместимой новой версии появятся описание выпуска и кнопка «Обновить».

Кнопка открывает установщик. Завершите его шаги, сохранив документы и закрыв КОМПАС перед установкой.

При недоступности GitHub повторите попытку позже. Сообщение об отсутствии совместимого выпуска означает, что пока нет стабильного опубликованного выпуска с пакетом для КОМПАС v22.
