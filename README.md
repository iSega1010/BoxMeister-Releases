# BoxMeister — библиотека для КОМПАС-3D

Публичный репозиторий для скачивания готовых сборок BoxMeister, публикации обновлений и пользовательской документации.

> Исходный код BoxMeister закрыт и в данном репозитории не публикуется.

## Загрузка и обновления

Готовые архивы и описание изменений будут размещаться в разделе **Releases**.
Для установки используйте инструкцию, приложенную к соответствующему выпуску.
Не загружайте файлы из неофициальных источников.
